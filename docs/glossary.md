# Glossary

- **MCU** — microcontroller; a tiny computer on one chip (e.g. ESP32).
- **SBC** — single-board computer running a full OS (e.g. Raspberry Pi).
- **GPIO** — general-purpose pins you can read or switch.
- **PWM** — pulse-width modulation; how servos receive their target angle.
- **I²C / SPI / I²S** — common wiring buses for sensors, displays and audio.
- **PSRAM** — extra RAM on some ESP32 boards; useful for displays and audio.
- **STL / STEP** — 3D file formats: STL for printing, STEP for editable CAD.
- **Stall current** — the current a motor draws when blocked; size your power supply for it.
- **Easing** — accelerating and decelerating motion so it looks natural.
